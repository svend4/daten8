# Обзор проекта: Classified Ads Indexer

## Введение

**Classified Ads Indexer** — это система автоматической индексации, классификации и мониторинга объявлений о бесплатной раздаче вещей с досок объявлений.

## Проблематика

На досках объявлений (eBay Kleinanzeigen, Craigslist и др.) ежедневно появляются тысячи объявлений о бесплатной раздаче предметов. Однако существует ряд проблем:

1. **Сложность поиска** — несмотря на большое количество объявлений, найти нужный предмет трудно из-за плохих каталогов и фильтров
2. **Отсутствие мониторинга** — невозможно отслеживать новые объявления в реальном времени
3. **Ручная категоризация** — нет автоматической классификации по темам
4. **Географическая фильтрация** — трудно найти объявления в конкретном городе или районе

## Решение

Система предоставляет комплексное решение:

### 1. Автоматический сбор данных
- Периодическое сканирование досок объявлений
- Извлечение структурированной информации
- Обнаружение дубликатов
- Поддержка множества источников

### 2. Интеллектуальная классификация
- Автоматическая категоризация с использованием Machine Learning
- Извлечение характеристик (состояние, бренд, размер)
- Кластеризация похожих объявлений
- Точность классификации ~85-90%

### 3. Геолокационная фильтрация
- Парсинг и стандартизация адресов
- Фильтрация по городу и району
- Расчет расстояния от пользователя

### 4. Система уведомлений
- **RSS/Atom ленты** — стандартный протокол подписки
- **Email-рассылки** — персонализированные дайджесты
- Гибкие фильтры по категориям, местоположению и ключевым словам

## Технические решения

### Выбор технологий

Проект использует **проверенные, простые технологии** без сложных зависимостей:

- **Python 3.11+** — основной язык программирования
- **SQLite/PostgreSQL** — реляционная база данных
- **Beautiful Soup** — парсинг HTML
- **scikit-learn** — классические ML-алгоритмы (TF-IDF, Naive Bayes)
- **feedgen** — генерация RSS/Atom лент
- **smtplib** — отправка email (стандартная библиотека Python)

### Почему без нейросетей?

1. **Простота** — не требуются GPU, большие объемы данных для обучения
2. **Эффективность** — низкие требования к ресурсам (можно запустить на Raspberry Pi)
3. **Прозрачность** — результаты классификации объяснимы
4. **Достаточная точность** — классические методы дают 85-90% точности для этой задачи

## Архитектура

Система состоит из 5 модулей:

```
┌──────────────┐
│   Crawler    │ ──► Сбор объявлений с досок
└──────┬───────┘
       │
       ▼
┌──────────────┐
│   Pipeline   │ ──► Очистка и нормализация данных
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  Classifier  │ ──► ML-классификация и кластеризация
└──────┬───────┘
       │
       ▼
┌──────────────┐
│   Database   │ ──► SQLite/PostgreSQL с индексами
└──────┬───────┘
       │
       ├──► RSS Generator ──► Статические RSS-файлы
       ├──► Email Sender ──► SMTP-рассылка
       └──► Web API (опц.) ──► REST API для интеграций
```

## Основные функции

### Для пользователей

1. **Подписка на RSS**
   ```
   /rss/berlin/computers.xml
   /rss/munich/furniture.xml
   /rss/all.xml
   ```

2. **Email-уведомления**
   - Настраиваемые фильтры (категории, города, ключевые слова)
   - Частота: немедленно / ежедневно / еженедельно
   - HTML-формат с изображениями

3. **Web-поиск** (опционально)
   - Полнотекстовый поиск
   - Фильтрация по всем параметрам
   - Просмотр на карте

### Для разработчиков

1. **Модульная архитектура** — легко добавить новый источник или классификатор
2. **REST API** — интеграция с другими сервисами
3. **Расширяемая схема БД** — добавление новых полей и таблиц
4. **Логирование и метрики** — мониторинг работы системы

## Примеры использования

### Сценарий 1: Поиск компьютеров в Берлине

**Пользователь:** Студент ищет бесплатный принтер в Берлине

**Действия:**
1. Подписывается на RSS: `/rss/berlin/computers.xml`
2. Добавляет ленту в RSS-ридер (Feedly, Thunderbird)
3. Получает уведомления о новых объявлениях в реальном времени

**Результат:** В течение недели находит подходящий принтер в своем районе

### Сценарий 2: Мониторинг мебели для новой квартиры

**Пользователь:** Семья переезжает в Мюнхен, нужна мебель

**Действия:**
1. Настраивает email-подписку:
   ```yaml
   categories: [furniture]
   city: München
   keywords: [sofa, schrank, tisch, stuhl]
   frequency: daily
   ```
2. Каждое утро получает дайджест с новыми объявлениями

**Результат:** За месяц обставляет квартиру бесплатной мебелью

### Сценарий 3: Коллекционер винтажных предметов

**Пользователь:** Коллекционер ищет винтажные вещи по всей Германии

**Действия:**
1. Создает подписку с ключевыми словами: `vintage, retro, antik`
2. Фильтрует спам-объявления: `exclude: [verkaufen, preis, euro]`
3. Получает немедленные уведомления

**Результат:** Находит уникальные предметы раньше других
